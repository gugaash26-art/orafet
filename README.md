## 🎮 Como usar

- python orafet.py -> Conversar com o ORAFET
- python pesquisar.py -> Pesquisar na internet
- python treinar_leve.py -> Treinar ele com seus textos
- python limpar.py -> Limpar e organizar o treino

## 🧠 Como ele aprende?

1. Você conversa com ele
2. Ele salva tudo em data/orafet/input.txt
3. Você roda python treinar_leve.py
4. Ele fica mais esperto no próximo papo

Quanto mais você fala, mais ele aprende seu jeito.
